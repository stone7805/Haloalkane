# 卤代烃 · 四类通关 V2.2

可离线运行的单文件课堂网页游戏。`index.html` 已包含样式、题库和脚本，不需要安装依赖或构建。适配手机和电脑：小屏以横向关卡导航、纵向题卡和点选/输入完成操作，不依赖拖拽。

## 重新上传到现有 GitHub Pages

你现有仓库是 `stone7805/Haloalkane`，更新后原网址仍为 `https://stone7805.github.io/Haloalkane/`。

1. 下载并解压 V2.2 GitHub 发布包。需要上传的是解压后的 `index.html`；不要直接把 `.zip` 文件上传成网页。
2. 打开 `https://github.com/stone7805/Haloalkane`，登录 GitHub。
3. 在仓库首页点击 **Add file → Upload files**。
4. 把 V2.2 的 `index.html` 拖入上传区。它与仓库原文件同名，提交后会更新网站首页。`README.md` 可一并上传，用于保存本说明。
5. 在 **Commit changes** 中填写 `更新卤代烃游戏至 V2.2`，选择直接提交到 `main` 分支，再点击 **Commit changes**。
6. 打开仓库的 **Actions** 或 **Settings → Pages**，等待部署完成。通常无需重新设置 Pages；仍应保持 `main` 分支和 `/(root)`。
7. 打开 `https://stone7805.github.io/Haloalkane/`，电脑按 `Ctrl+F5` 强制刷新；手机关闭旧页面后重新打开。页眉显示 **V2.2**，成绩单完成提示和总成绩均为红色，即表示更新成功。

如果网站仍显示 V2.1，先等待几分钟再刷新。不要删除浏览器的网站数据，否则本机训练记录也会被清除。

可直接双击 `index.html` 在本机离线练习。GitHub 官方部署说明：[Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 游戏规则

- 四关各 25 分，共 12 个小任务、满分 100 分：命名侦探、结构简式工厂、异构体工坊、证据鉴别室。
- 先输入班级、姓名和**10 位数字学号**并勾选核对；点击“锁定身份并开始”才启动本次活动。编号以点击时的设备本地时间、学号末两位和姓名拼音首字母组成。
- 完整作答才计一次正式提交；答错后继续核对，每多一次正式提交扣 2 分，单题最低保留该题满分的 60%。
- 正式答错的任务，**正式通过以后**还需独立重练正确。全部正式任务及必修错题完成后才开放成绩单与 A4 打印/PDF。
- 结构简式题接受明确表示连接关系的直链结构简式及反向写法；异构体题的多选项标有 A–F。
- 第四关先根据现象线索排序操作，再运行未知样品模拟取得沉淀记录，独立判断卤离子与证据的适用范围。题干、提示和第二问的选项都不会提前写出未知样品的正确卤素；完整颜色对照在末题通过后的通关页和只读复盘中出现。
- 实验是课堂简化模拟，不是实际检验操作指南；沉淀颜色不能单独确认完整碳骨架。

## 数据与设备

进度只保存在**当前浏览器的本地存储**。不同手机、电脑、浏览器、无痕窗口之间不会自动同步；GitHub Pages 静态站点也不会集中收集成绩。请在同一设备同一浏览器继续，并在通关后打印或另存 PDF 作为可移交记录。浏览器清理网站数据会删除本机进度；同一浏览器会话只对应一名学生。身份锁定与记录校验用于课堂流程约束，并不是防篡改的服务器认证。

如果已有异常记录，页面会提示并保护旧数据，不会默默覆盖。若教师决定重新开始，请先核对或留存旧记录，再清理该站点的浏览器数据。V2.2 会在同一网址、同一浏览器中复制并恢复合法的 V2.1 训练记录，原 V2.1 记录仍保留；换设备、换浏览器或清除网站数据后无法恢复。
